# Claims Reserving: Chain Ladder vs. Bornhuetter-Ferguson

Loss reserving analysis on CAS Schedule P private passenger auto data
(State Farm Mut Grp, accident years 1988-1991), with CPI-U inflation
adjustment and back-testing against actual outcomes.

- Code: reserving_ppauto.R (R)
- Report: CLAIMS RESERVING.pdf
- Data: CAS Loss Reserving Database (NAIC Schedule P), via the casdata R package
